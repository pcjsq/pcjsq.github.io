# 陕西省人身损害赔偿计算器

未成年人场景优先的单文件网页计算器，依陕西省现行裁判口径估算人身损害赔偿金额。

## 使用

双击打开 `index.html` 即可，无需联网、无需部署。

GitHub Pages 部署：仓库 Settings → Pages → Branch 选择 `main` / root，即可获得在线链接。

## 计算口径

| 基数（2025年度） | 金额 | 用途 |
|---|---|---|
| 城镇居民人均可支配收入 | 49,053 元/年 | 残疾赔偿金 |
| 城镇居民人均消费支出 | 29,807 元/年 | 被扶养人生活费 |
| 居民服务业（私营） | 46,797 元/年 | 护理费 |
| 私营单位平均工资 | 59,774 元/年 | 城镇无固定收入误工费 |
| 农林牧渔（私营） | 38,514 元/年 | 农村无固定收入误工费 |

- 主要依据：《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释（2022修正）》、《陕西省道路交通事故损害赔偿项目计算标准（试行）》〔陕高法〔2020〕45号〕、《民法典》第1179条。
- 未成年人专项：误工费原则不计（可手动开启）、残疾赔偿金按20年全额、护理人数可依医嘱计2人。
- 内置 2025 / 2024 两个年度口径切换，应对法院沿用旧统计年度的情形。

## 免责声明

仅供估算与谈判参考，不构成法律意见。三期天数、伤残等级、责任比例等以司法鉴定意见及法院认定为准。
